# Produktionsworkflow

Idee → Recherche/Rechte → Dreh → Schnitt/Musik → Thumbnail/Titel → Qualitätscheck → Upload → Auswertung

## Vor jeder Veröffentlichung
- [ ] Ton, Bild und Untertitel geprüft
- [ ] Bild-, Musik- und Drohnenrechte geklärt
- [ ] Thumbnail, Titel, Beschreibung und Links kontrolliert
- [ ] Backup der Originaldateien erstellt
- [ ] Nach Veröffentlichung erste Kennzahlen notiert
